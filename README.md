# Fit für die Klassenarbeit: Energie – Physik Klasse 8

Übungs-App zur Vorbereitung auf die Klassenarbeit Energie: https://maltefehling.github.io/physik-ka-energie/

- Wahl: ein Bereich (Abschnitte wie im OneNote-Heft/Kompetenzraster) oder ganze Klassenarbeit, jeweils ★/★★/★★★.
- Aufgaben werden auf Papier gelöst und mit der Ideallösung verglichen. Bei Rechenaufgaben wird nur das Endergebnis eingegeben; die App prüft es und schließt aus falschen Ergebnissen auf typische Fehler (Einheit nicht umgerechnet, Formel falsch umgestellt, Zwischenergebnis, Bruch umgedreht …). Danach erscheint die Aufgabe im perfekten Fünf-Schritt.
- Jede Aufgabe hat einen Tipp-Knopf (bei Rechenaufgaben gestufte Tipps: gesucht → Umrechnen → Zwischenschritt → Formel).
- Jede Aufgabe hat Kontext-Varianten mit Zufallszahlen aus festen Bereichen (gleiches Niveau), auch die Aufgaben mit Material im IQB-Stil (Kompetenzbereich + Anforderungsbereich).

Reine HTML-Datei, kein Server, keine Datenerfassung.
